# Security Policy

## Supported versions

Security reports are accepted for the latest stable release of SCI Design Blocks. The current stable release is 1.4.0 and requires WordPress 7.1+ and PHP 7.4+.

The unreleased 1.5.0 development candidate has a Product Owner-approved minimum of PHP 8.3+ (2026-10-13). This does not change the requirements or support status of stable 1.4.0. Security reports are still accepted for the latest stable release.

## Report a vulnerability

Please use GitHub’s **Report a vulnerability** action in the repository’s **Security** tab. Private vulnerability reporting is enabled for this repository. Include steps to reproduce, affected versions, and impact when known.

Please do not open a public issue, discussion, or pull request with an unpatched vulnerability. The maintainers will coordinate investigation and disclosure through GitHub’s private reporting workflow.
