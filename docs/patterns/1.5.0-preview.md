# SCI Design Blocks 1.5.0 development pattern preview

This inventory describes the unreleased M7/M8 development branch. It contains 27 patterns, 83 icons, seven Core Block Styles, and three CSS files; the five patterns below are the M8 additions. They are not in the stable 1.4.0 download; availability in the inserter depends on using the development source/candidate. The minimum for the 1.5.0 candidate is WordPress 7.1 and PHP 8.3. In Gutenberg, open the block inserter's **Patterns** tab and select **SCI Design Blocks**.

| Pattern | Purpose | Editable elements / suggested use | Known limitations |
| --- | --- | --- | --- |
| Section — Intro | Centered opening for a content section. | Eyebrow, H2, paragraph, alignment and spacing; use before a related content group. | Sample copy should be replaced. Theme typography and spacing vary. |
| Benefits — Grid | Present three related benefits together. | Section heading/intro and each card heading/description; use for outcomes or capabilities. | Uses text-only cards; centering is available through normal Core controls. |
| Services — Image Cards | Overview of image-led offerings. | Three Core images (select media and set meaningful alt), headings, descriptions and example links. | Images start empty and require media selection in the editor; replace example destinations. Frontend layout was measured at 1440, 1024, 768, 390, and 320 px in Twenty Twenty-Five and Twenty Twenty-One. Interactive Gutenberg editing/save/reopen and formal accessibility certification remain pending. |
| Pricing — Split Offer | Explain one offer beside its features. | Offer title, description, sample amount, CTA and semantic feature list. | Illustrative sample price/copy; replace before use. Not a multi-plan comparison. |
| CTA — Horizontal | Pair a message with a prominent action. | Heading, paragraph and button; edit its example target and label. | Uses a two-column composition that stacks on mobile; final styling is theme-native. |

The branch also contains the existing Hero Cover and Hero Split additions alongside the stable 1.4.0 library. All five new patterns use editable Core blocks. No newsletter processing, global Header/Footer builder, custom block, frontend JavaScript, or additional CSS is provided. RC.8 is a local candidate, not an approved or published release. Gutenberg insertion/edit/save/reopen and formal accessibility certification remain distinct from structural and frontend layout checks; see the [M9 final QA report](../architecture/M9-FINAL-QA-REPORT.md) for current evidence and open gates.
