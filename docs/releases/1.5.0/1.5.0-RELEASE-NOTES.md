# SCI Design Blocks 1.5.0

**Publication status:** Release preparation; not yet published.

SCI Design Blocks 1.5.0 expands the Gutenberg-native pattern library while keeping inserted compositions editable WordPress Core blocks.

## Highlights

- Seven new patterns: Hero Cover, Hero Split, Section Intro, Benefits Grid, Services Image Cards, Pricing Split Offer, and CTA Horizontal. The library now contains 27 patterns.
- 83 curated SVG icons and seven optional Core Block Styles remain available, with three CSS files.
- Commercial sections support full-width layouts; Services cards use a responsive Core grid with editable image placeholders and aligned calls to action.
- Pricing CTA alignment, Hero Cover overlay contrast, and block-style CSS cache versioning are improved.
- Gutenberg serialization corrections address invalid Core block markup found during testing.
- Example buttons remain editable Core Buttons and explain that authors must configure a real destination before publishing; no misleading fragment URL is fabricated.

## Requirements and compatibility

- WordPress 7.1 or later.
- PHP 8.3 or later.
- GPL-2.0-or-later.
- No SCI custom blocks, SCI-owned frontend JavaScript, or new runtime dependencies.
- Existing content remains ordinary WordPress Core blocks. Stable 1.4.0 remains an unchanged historical release with its original PHP 7.4 minimum.

## QA scope

PHP and Python regressions, pattern/parser/serializer checks, package integrity, WordPress installation and upgrade, and content preservation are recorded in the final release report. The Product Owner confirms manual Gutenberg insertion/editing/saving/reopening and corrected CTA destination tests. This release does not claim formal WCAG certification or exhaustive assistive-technology testing.
